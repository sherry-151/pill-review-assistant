# 拍攝流程 v0.2

## 已採用的實際設定（優先於下方初始建議）

依使用者2026-10-16補充，三批皆沿用三光源設定：Panasonic 42.5W LED遙控吸頂燈 LGC61201A09（使用者提供6–8坪款，全燈模式）、CYKE F662手機補光燈、Dr.Light T5 LED檯燈。兩盞補光設備依使用者先前描述使用最亮白光模式；實際色溫、照度、顯色性未量測，不記作已知5000 K；全燈模式不直接推定為特定色溫。

相機為iPhone 18 Pro，工作設定為鏡頭至藥品平面15 cm、2×、JPEG；背景為燕麥色日本丹迪紙。曝光/白平衡鎖定狀態與各批燈位尚待確認，不把操作建議當成已完成紀錄。

- session01：四類各20張，共80張，規劃供訓練使用。
- session02：四類各10張，共40張，規劃供驗證/調參使用；檔案配對、矩形標籤、座標與影像方向尺寸檢查通過，尚未全數人工視覺審核。
- session03：四類各10張，共40張，預留為最終測試，不得參與調參；檔案配對、矩形標籤、座標與影像方向尺寸檢查通過，尚未全數人工視覺審核。

使用者確認session02與session03拍攝前均重新架設設備並重新擺放藥品。這是同一取像環境的分批測試，不等同跨院所、跨相機或跨背景外部驗證。資料固定按session01/02/03分為train/val/test，共80/40/40張，不採隨機混批切分。

現有資料是混合室內照明下的試驗，不宣稱為已校準的光學環境。後續改成兩光源或更換背景時，使用新批次名稱另記條件，不覆寫舊批次資訊。

## 初始建議（歷史規劃，非目前實拍紀錄）

以下為起始實驗規格，須以10張試拍確認清晰度後才大量收集。

1. iPhone 主相機 1x、一般照片、4:3；固定輸出解析度，關閉濾鏡、閃光、肖像與 Live Photo；避免自動切換微距鏡頭。若無法固定鏡頭，記錄實際鏡頭與EXIF。
2. 鏡頭到藥錠平面先設30 cm，垂直向下90度。20/30/40 cm試拍，選刻痕清晰且無須自動切鏡的距離，固定後記錄。不用數位變焦補救模糊。
3. 霧面中性灰背景，固定約15 x 20 cm取像區；藥錠置中央。同一類不能總固定在某位置。品項標籤不出現在模型輸入影像中。
4. 兩側漫射LED以約45度照射，先固定約5000 K；避免日光與室內黃光混合。擴散罩勿接觸發熱燈具。不以直射環形燈作唯一預設。
5. 每批鎖定對焦與曝光（若相機介面支援），記錄設定。固定白平衡若不可行，保留自動白平衡狀態紀錄；每批另外拍灰卡參考照。
6. 先做裸錠：翻面、旋轉、不同擺放與日期。再做透明袋：記錄袋材、袋號、反光與遮蔽。連拍不算多個獨立樣本。
7. 原始照片完整備份，HEIC若需轉JPEG，另存衍生圖並記錄工具版本與轉換設定，不覆蓋原始檔。
8. 至少預留樹莓派相機獨立測試批次。iPhone 測試結果不能代替樹莓派實拍結果。
