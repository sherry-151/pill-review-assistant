# 拍攝流程 v0.1

以下為起始實驗規格，須以10張試拍確認清晰度後才大量收集。

1. iPhone 主相機 1x、一般照片、4:3；固定輸出解析度，關閉濾鏡、閃光、肖像與 Live Photo；避免自动切換微距鏡頭。若無法固定鏡頭，記錄實際鏡頭與EXIF。
2. 鏡頭到藥錠平面先設30 cm，垂直向下90度。20/30/40 cm試拍，選刻痕清晰且無須自動切鏡的距離，固定後記錄。不用數位變焦補救模糊。
3. 霧面中性灰背景，固定約15 x 20 cm取像區；藥錠置中央。同一類不能總固定在某位置。品項標籤不出現在模型输入影像中。
4. 兩側漫射LED以約45度照射，先固定约5000 K；避免日光與室內黃光混合。擴散罩勿接觸發熱燈具。不以直射環形燈作唯一預設。
5. 每批鎖定對焦與曝光（若相機介面支持），記錄設定。固定白平衡若不可行，保留自動白平衡狀態紀錄；每批另外拍灰卡参考照。
6. 先做裸錠：翻面、旋轉、不同擺放与日期。再做透明袋：記錄袋材、袋號、反光與遮蔽。連拍不算多個獨立樣本。
7. 原始照片完整備份，HEIC若需轉JPEG，另存衍生圖并記錄工具版本与转换設定，不覆盖原始檔。
8. 至少预留树莓派相机独立测试批次。iPhone测试结果不能代替树莓派实拍结果。
