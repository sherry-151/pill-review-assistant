# 新相機灰色與燕麥色背景探索性對照

日期：2026-10-25。執行裝置為 Mac CPU；燕麥色背景這批尚未在 Pi CPU 重跑。以原 best.pt、conf 0.25、imgsz 640、NMS IoU 0.7、max_det 300、rect True、CPU FP32、augment False、agnostic_nms False 進行整張影像推論，不重新訓練、不調門檻、不裁切或增強，也不刪除失敗案例。

## 資料與可追溯性

使用者表示更換燕麥色背景，其他拍攝條件不變；沿用先前 15 cm、正常倍率的取像流程。兩批各為四類藥物單顆照片與空背景，共五張；全部為 4608 × 2592、EXIF orientation 1。來源內容未覆寫，推論時仍統一處理 EXIF 方向。

- 燕麥色背景原圖：`data/raw/camera-v3-燕麥背景/`
- 灰色背景原圖現址：`data/raw/camera-v3-灰背景/`
- 案例對應清單：`data/splits/camera-v3-oatmeal01.json` 與 `data/splits/camera-v3-gray01.json`。

灰色背景原先名為 `camera-v3-minimal01/v2-*.jpg`，現在資料夾與檔名已改為上述位置的 `v3-*.jpg`。五張現檔與舊報告的 SHA-256 全部相同，確認只是命名／位置不同。此處保留現名與歷史紀錄，不回改舊輸出。

為保留兩批現有檔名，測試程式新增可選 `--cases` JSON 清單，並忽略 Finder 的 `.DS_Store`；清單仍強制四類各一張與一張空背景，實際擺放只作事後核對，不輸入模型。推論設定與影像處理方式未改變。兩批皆用同一版程式重跑，模型、程式雜湊、環境與推論設定一致；灰色背景重跑的所有類別、分數與座標與舊 Mac v002 結果完全相同。

## 結論與限制

在本次重拍案例與固定設定下，改成燕麥色背景**沒有改善類別與數量核對的結果**，辨錯及漏辨仍存在；也不能宣稱原手機模型已可靠適用新相機。drug001 仍高信心辨錯，信心值不能當作正確機率；drug002 此張雖通過固定門檻，不能據此宣稱穩定可靠。

這不是「背景完全沒有影響」的證據，也不能把 drug002 分數下降直接歸因於背景。兩批是重新擺放及拍攝，藥錠位置、旋轉方向不同；相機自動對焦、曝光與白平衡尚未提供鎖定或量測紀錄。目視燕麥批的 drug003 刻印與輪廓也較柔，尚未定量確認對焦或震動因素。因此，這是以更換背景為主要操作的探索性對照，不是其他變因全部嚴格一致的因果實驗。

後續可先量測既有手機照片與新相機照片中藥錠占畫面的比例，再規劃固定背景下的取景範圍／目標尺度對照，同時確認對焦與曝光。不能直接假設相機使用 2× 就會改善；新嘗試另建版本，保留本批及灰色背景失敗基準，不選擇性排除失敗影像。
