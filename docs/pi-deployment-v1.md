## 限制與下一步

這是既有手機照片在不同運算裝置上的核對，不是 Pi 相機的泛化測試。結果僅涵蓋四類、同場景、單顆靜態影像；不稱臨床辨識正確率 100%。兩端 Python、部分依賴與運算後端不同，無法把差異歸因於單一因素。

耗時為各自一次驗證流程的階段平均，不含拍照、網路、完整啟動及流程等待，也不是連續運作穩態或嚴謹速度比測試；不據此宣稱達到藥包機即時需求。接下來先做預期品項／數量比對原型，取像改善與第二版模型另開實驗版本。完整影像、模型及輸出均被 Git 忽略，需另作私人備份。
