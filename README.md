# 藥錠辨識與覆核輔助原型

研究者：張筱唯。用途：研究所申請之可重現實作原型。

## 目前狀態

2026-10-19：完成四類藥物基準訓練、跨拍攝批次測試及接觸／遮蔽探索性評估。
過往實驗程式未留存，舊數字不視為本專案的驗證結果。

目標成品：以 Raspberry Pi 5 與相機建置小型視覺複核設備，架於藥包機出藥口附近，提供品項／數量辨識與人工複核提示。此為待驗證的研究原型，不直接控制藥包機，也不取代藥師核對。動機來自研究者接觸的設備缺乏機器視覺檢查，不概括所有市售藥包機。

目前已在 Mac 上完成離線照片評估；尚未完成樹莓派部署、透明藥包／動態出藥與現場安全驗證。研究摘要見 [一頁研究紀錄](docs/research-note-v1.md)，後續部署方向亦列於該紀錄。

## 第一階段範圍

四種藥錠的影像偵測，包含至少一組外觀相似品項。先固定取像條件，完成基準模型，再測試透明藥包及樹莓派相機。

## 資料夾

- docs/：環境與拍摄流程
- data/raw/：原始影像（不進 Git）
- data/labels/：標註（不進 Git，須另外備份）
- data/splits/：固定切分清單
- scripts/：取像、訓練、推論、評估程式，後续加入
- outputs/：結果及模型（不進 Git，須另外備份）

## 重現規則

記錄 Python 與套件版本、Git commit、資料版本、切分清單、模型設定與亂數種子。測試資料不參與調參。每個環境分別產生鎖定檔；Mac 訓練與 Raspberry Pi 推論的套件可能不同。

Mac 已建立 Python 3.11.17 虛擬環境；每次實驗另存實際套件版本與裝置紀錄。docs/environment.md 保留早期環境規劃，實際版本以實驗輸出為準。

## 備份與公開

每完成一項功能提交 Git。原圖、標註、權重與结果另外同步至私人備份，Git 本身不包含被忽略的檔案。公開前確認影像授權且未含病人資訊。
