# 藥錠辨識與覆核輔助原型

研究者：張筱唯。用途：研究所申請之可重現實作原型。

## 目前狀態

2026-10-25：Camera Module 3 的五張最小測試照片已在 Mac 與 Raspberry Pi 5 CPU 完成固定設定離線推論。權重、照片、程式雜湊與設定一致，五張類別與數量跨裝置一致；但四張有藥照片只有一張符合，另有一張辨錯與兩張漏辨，空背景一張無誤報。這是可重現的失敗基準，不是新相機辨識成功或完整取像／數量比對示範。詳見 [新相機最小測試與 Pi 比對紀錄](docs/camera-v3-minimal01.md)。

2026-10-21：新增預期品項／數量比對原型。以固定 best.pt、conf=0.25 在 Mac 與 Raspberry Pi 5 CPU 完成五個安排案例，涵蓋一致、缺少、多出、品項替換及空背景；兩端各類數量一致，Pi 處理錯誤為 0。模型、照片、設定與執行程式雜湊相同。這是手機靜態照片的流程示範，不是獨立準確率、Pi 相機或臨床放行驗證。詳見 [數量比對原型紀錄](docs/countcheck-prototype-v1.md)。

2026-10-20：完成四類藥物基準訓練、跨拍攝批次測試及接觸／遮蔽探索性評估；新增 Raspberry Pi 5 CPU 的 40 張既有手機測試影像離線評估及 Mac／Pi 同圖核對。
過往實驗程式未留存，舊數字不視為本專案的驗證結果。

目標成品：以 Raspberry Pi 5 與相機建置小型視覺複核設備，架於藥包機出藥口附近，提供品項／數量辨識與人工複核提示。此為待驗證的研究原型，不直接控制藥包機，也不取代藥師核對。動機來自研究者接觸的設備缺乏機器視覺檢查，不概括所有市售藥包機。

目前 Mac 與 Pi 的 40 張單顆測試皆在固定 conf=0.25、同類別一對一 IoU≥0.50 下完成 40/40 張配對，無額外框；同圖類別與數量一致。這不是臨床正確率 100%，也不是 Pi 相機或即時出藥測試。

既有手機影像部署結果見 [樹莓派部署紀錄](docs/pi-deployment-v1.md)，新相機進度見 [最小測試紀錄](docs/camera-v3-minimal01.md)。[一頁研究紀錄](docs/research-note-v1.md) 保留 2026-10-19 的歷史狀態。舊相機曾有清晰度問題，新 Camera Module 3 已能遠端拍照並完成五張探索性模型測試，但辨識尚不可靠；仍未完成獨立大批相機評估、透明藥包／動態出藥與現場安全驗證。

## 第一階段範圍

四種藥錠的影像偵測，包含至少一組外觀相似品項。先固定取像條件，完成基準模型，再測試透明藥包及樹莓派相機。

## 資料夾

- docs/：環境與拍摄流程
- data/raw/：原始影像（不進 Git）
- data/labels/：標註（不進 Git，須另外備份）
- data/splits/：固定切分清單
- scripts/：取像、訓練、推論、評估程式，後续加入
- outputs/：結果及模型（不進 Git，須另外備份）

## 重現規則

記錄 Python 與套件版本、Git commit、資料版本、切分清單、模型設定與亂數種子。測試資料不參與調參。每個環境分別產生鎖定檔；Mac 訓練與 Raspberry Pi 推論的套件可能不同。

Mac 已建立 Python 3.11.17 虛擬環境；每次實驗另存實際套件版本與裝置紀錄。docs/environment.md 保留早期環境規劃，實際版本以實驗輸出為準。

## 備份與公開

每完成一項功能提交 Git。原圖、標註、權重與结果另外同步至私人備份，Git 本身不包含被忽略的檔案。公開前確認影像授權且未含病人資訊。
